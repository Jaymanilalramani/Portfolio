## ✨ Features

- 🎨 **Dark / Light theme toggle**
- ⌨️ **Typing animation** in hero section
- 📱 **Fully responsive** (mobile, tablet, desktop)
- 🎯 **Smooth scroll** navigation with active link highlight
- ⚡ **Scroll-triggered fade-in animations**
- 🃏 **Project cards** with Problem → Solution → Result
- 📅 **Vertical timeline** for experience
- 📜 **Certifications grid**
- 📬 **Contact form** with validation
- ⬆️ **Back-to-top** floating button
- 🎭 **Hover effects** & glassmorphism touches
- ⬇️ **Resume download** button
