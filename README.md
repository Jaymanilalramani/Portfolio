## ✨ Features

- 🎨 **Dark / Light theme toggle** — smooth transition
- ⌨️ **Typing animation** in hero section for roles
- 📱 **Fully responsive** — mobile, tablet, desktop
- 🎯 **Smooth scroll navigation** with active link highlight
- ⚡ **Scroll-triggered fade-in animations** for each section
- 🃏 **Project cards** with Problem → Solution → Result stories
- 📅 **Vertical timeline** for experience & achievements
- 📬 **Working contact form** with validation
- ⬆️ **Back-to-top** floating button
- 🎭 **Hover effects** & glassmorphism touches
- 🚀 **No build tools** — pure HTML, CSS, JavaScript
